# Changes — one file per tab

Every UI change in this prototype gets an entry here. A change with no entry is invisible
at handoff and will not get built.

Format for each file:

```markdown
# <Tab name>

## What changed
Plain description of the difference from V1.

## Why
Where the request came from — meeting + timestamp, or Lloyd's decision.

## What the backend needs
The data or endpoint required. "Nothing new" is a valid and welcome answer.

## Open questions
Anything still undecided. Empty when settled.
```
