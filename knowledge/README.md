# Knowledge Base

Behavioural facts discovered while working on this repo — things that are true but not
obvious from reading the code.

Write short files (10-30 lines) with front-matter tags:

```markdown
---
tags: [portal, fixtures, fetch-shim]
last_updated: YYYY-MM-DD
---
```

Files are loaded at session start by matching tags to the task at hand. Add to this
whenever something surprises you.
